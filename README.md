# 📧 Spam Detection using TF-IDF and Logistic Regression

A Natural Language Processing (NLP) project that classifies messages as Spam or Not Spam using TF-IDF feature extraction and Logistic Regression.

This project demonstrates a classical Machine Learning approach to text classification.

---

# 🚀 Features

✅ Text Cleaning

✅ TF-IDF Vectorization

✅ Logistic Regression

✅ Train-Test Split

✅ Spam Classification

✅ Real-Time Prediction

✅ NLP Preprocessing Pipeline

---

# 🧠 Machine Learning Pipeline

Raw Message

Text Cleaning

TF-IDF Vectorization

Feature Matrix

↓

Spam / Not Spam

---

# 📂 Dataset

The dataset contains spam and non-spam messages.

Examples:

Spam:

- Win money now
- Claim your free prize
- Earn money quickly
- Free iphone click now

Not Spam:

- Please call me later
- Meeting starts at five
- Send me the report
- See you tomorrow
